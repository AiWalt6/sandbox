Assignment 10

Submission link:
https://github.com/AiWalt6/sandbox/tree/main/assignment_10

Run with Python 3 from the repository root:
  python3 assignment_10/pet_manager.py
  python3 assignment_10/patient_manager.py
  python3 assignment_10/employee_manager.py

No extra packages are needed. Each class is in its own module, with
__init__ first, private double-underscore attributes, matching getters
and setters for every attribute, and __str__ last.

Pet: name, animal type, and age, with output labels matching the sample.
Age must be a nonnegative whole number.

Patient: all ten fields shown in the document are collected, rather than
only the three fields in the attached starter. The create_patient(),
create_procedure(), and main() functions from the skeleton are retained.
The procedure loop accepts zero or multiple procedures, as the skeleton
requests, and re-prompts for invalid y/n answers. Enter y for each
procedure and n when finished. Each procedure records its description,
date, practitioner, and charge. Charges must be finite and greater than
zero, and each charge and the total print with two decimal places.
Dates, ZIP codes, and phone numbers are kept as text.

Employee: the document references an employee-manager skeleton that was
not attached. With approval, the client was written using the same menu
pattern as Assignment 9, matching the document's menu and field labels.
Employees are stored in a dictionary keyed by ID number. IDs remain
strings to preserve leading zeros. Duplicate IDs are rejected. Changing
an employee uses its setters and preserves the ID. Lookup, add, change,
and delete receive the dictionary of Employee objects as an argument.

employees.dat is stored beside the client, regardless of the working
directory. Successful changes are saved immediately, and quitting saves
again. Missing and empty files start an empty directory. Corrupt data
and file errors are reported rather than silently overwritten. Only
unpickle trusted files created by this program.

Testing screenshots show browser-rendered transcripts of actual program
runs and automated checks. All demonstration records are fictional.
The included employees.dat contains an empty pickled dictionary, so the
directory starts clean. Submit the link and included PNG screenshots.

The document's pet_manger.py filename is treated as a typo: its client
is named pet_manager.py, matching the name used elsewhere in the document.
Lecture slides were not attached; implementations follow the supplied
class structure sample and the document's listed Chapter 10 techniques.
