Assignment 8

Run these programs with Python 3. No additional packages are needed:
  python3 assignment_8/password_validation.py
  python3 assignment_8/parse_date.py
  python3 assignment_8/grades_stats.py

grades.csv contains the exact header and five student records from the
provided grades.xlsx. The grade program retains all function names and
weight constants from grades_stats_skeleton.py. It reads grades.csv next
to the script, regardless of the terminal's working directory.

The category averages are weighted as follows: tests 30%, exams 30%,
discussions 20%, and project 20%. Grades are classified without rounding.
The supplied data produces counts of 2, 3, 0, 0, and 0.

Passwords are not stripped: leading and trailing spaces are invalid.
Dates allow one- or two-digit months and days, and a four-digit year.
Surrounding date whitespace is removed. Invalid calendar dates, including
February 29 in non-leap years, are rejected.

Testing screenshots show browser-rendered transcripts of actual program
runs and automated checks, not VS Code terminal screenshots.
Submit the GitHub link to assignment_8 with the included screenshots.
