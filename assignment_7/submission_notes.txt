Assignment 7 - Running and Submission

Run precipitation_analysis.py first. It writes precipitation.txt next to
the scripts. Then run precipitation_chart.py to read that file, save
precipitation_chart.png, and display the chart.

Environment setup (Mac, local coursework workspace):
1. Open the parent coursework folder in VS Code.
2. Create one shared environment: python3 -m venv .venv
3. Open a new terminal and activate: source .venv/bin/activate
4. Install the dependency: python -m pip install -r requirements.txt
5. Use Python: Select Interpreter and select .venv/bin/python.
6. Use Run Python File, not Run Code, to run each script.

If the coursework workspace is in OneDrive, create the environment
outside OneDrive instead: python3 -m venv ~/venvs/python
Activate it with: source ~/venvs/python/bin/activate
Select that interpreter in VS Code. Recreate the environment on each
computer; do not copy it or upload it to GitHub.
