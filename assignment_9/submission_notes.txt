Assignment 9

GitHub submission:
https://github.com/AiWalt6/sandbox/tree/main/assignment_9

Run from the repository root with Python 3:
  python3 assignment_9/capital_game.py
  python3 assignment_9/word_count.py
  python3 assignment_9/email_menu.py

No extra packages are required. The three programs use introductory
dictionaries, sets, loops, functions, and pickle serialization.

Capital game: 15 states are selected randomly. Enter 0 to quit and see
correct and incorrect totals. Answers ignore surrounding whitespace and
letter case. Quitting does not count as an answer.

Word count: enter text.txt to use the supplied attachment. Relative input
paths are resolved next to the script; absolute paths also work. Words
are separated by whitespace. Capitalization and punctuation are retained
to match the sample output. A set removes duplicate words and a dictionary
stores their counts. Results are sorted for readable, repeatable output.

Email menu: all function names and constants from the supplied skeleton
are retained. Names are case-sensitive, matching the sample. Empty names
and addresses are rejected. Changes are saved immediately; quitting also
saves. Missing or empty email.dat files start with an empty dictionary.
Other invalid data and file errors are reported rather than overwritten
silently. The included email.dat contains an empty pickled dictionary.
Only use trusted email.dat files created by this program: unpickling
untrusted files is unsafe. No email-format validation was requested.

Testing screenshots are browser-rendered transcripts of actual Python
execution and automated checks, not screenshots of a VS Code terminal.
The screenshots include correct/incorrect/quit capital responses, word
counts, all email operations, validation, and persistence across runs.
